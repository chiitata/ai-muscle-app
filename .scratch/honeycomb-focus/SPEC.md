# Honeycomb Focus — 仕様書 (v1)

ミツバチ🐝テーマのポモドーロ・タイマー ＋ 軽量タスクボード。
1画面で完結・バックエンドなし（localStorage）・Vercel本番デプロイ前提。

## 1. コンセプト
「集中を積み重ねると、はちみつ🍯が溜まっていく」小さな達成感を軸にした
シングルページの集中支援アプリ。アカウント登録不要、開いてすぐ使える。

## 2. 設計原則
- **1画面完結**: スクロールなしで主要操作が見渡せる。
- **状態は端末内のみ**: localStorage に保存。サーバー・ログイン不要。
- **軽い達成感**: 1ポモドーロ完了ごとに🍯が1滴、ジャーが満ちていく。
- **アクセシブル**: キーボード操作可・タイマー残時間は `aria-live` で読み上げ。

## 3. 画面構成（単一ページ）
```
┌──────────────────────────────────────────┐
│  🐝 Honeycomb Focus            [🍯 x 3]   │  ← ヘッダー＋はちみつカウンタ
├──────────────────────────────────────────┤
│                25:00                       │  ← タイマー（大きく中央）
│           集中モード / 休憩モード           │
│        [ ▶ スタート ] [ ⏸ ] [ ↺ ]        │
├──────────────────────────────────────────┤
│  今日のタスク                              │
│  ○ 仕様書を書く            ← 実行中★       │
│  ○ READMEを書く                    [🗑]   │
│  [ ＋ タスクを追加 ]                        │
├──────────────────────────────────────────┤
│  🍯 はちみつジャー  ▓▓▓░░░  3/6           │  ← 進捗ビジュアル
└──────────────────────────────────────────┘
```

## 4. 機能詳細
### 4.1 タイマー
- 既定: 集中 25:00 / 休憩 5:00。
- 操作: スタート / 一時停止 / リセット。
- 集中セッション完了で自動的に休憩へ切替（逆も同様）。
- 完了時に🍯を+1、当日のポモドーロ数をカウント。
- 残り時間は1秒ごとに更新し `aria-live="polite"` で通知。

### 4.2 タスク
- 追加 / 完了トグル / 削除。
- 1つを「実行中(active)」に指定でき、タイマーと紐づく（任意）。
- 空のときは温かいエンプティステートを表示（UIコピー参照）。

### 4.3 はちみつジャー（報酬）
- 1ポモドーロ完了で1滴。ジャーは6滴で満タン→満タンで祝福メッセージ＋リセット可。
- 見た目は段階的に満ちるバー or SVGジャー（実装はPollen判断でOK）。

### 4.4 永続化
- `localStorage` キー `honeycomb-focus:v1` に `{ tasks, honeyCount, settings }` を保存。
- 読み込み失敗時は初期状態にフォールバック（クラッシュさせない）。

## 5. 状態一覧
- タイマー: idle / running(focus) / running(break) / paused。
- タスクリスト: 空 / 通常 / 全完了。
- ジャー: 0〜6滴 / 満タン。

## 6. 非目標（v1では作らない）
- アカウント・ログイン・サーバー同期。
- 通知（OS通知）。※余力があれば完了時のサウンド/タイトル点滅のみ検討。
- 設定の細かなカスタマイズ（時間変更は余力があれば）。

## 7. 技術
- Next.js (App Router) + TypeScript + Tailwind CSS。
- クライアントコンポーネント中心（`"use client"`）。状態は `useReducer` or カスタムフック。
- Vercel へ `vercel --prod` でデプロイ。
