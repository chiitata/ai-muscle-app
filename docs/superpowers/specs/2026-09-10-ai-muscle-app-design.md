## 📋 1. プロジェクト概要

### 目的
個人ユーザーが日々の筋トレメニューを効率的に記録・管理するAndroidアプリを開発する。特に、自然言語入力でAIが筋トレメニューと回数を自動変換することで、メニュー入力の手間を削減する。

### 対象ユーザー
- 個人トレーニングユーザー（ジム通い者、ホームトレーニング）
- メニュー管理と進捗トラッキングを求めるユーザー

### 主な要件
- ✅ 自然言語入力で筋トレメニューをAI変換（オフライン処理）
- ✅ メニュー履歴の保存・再利用（テンプレート機能）
- ✅ Google Play Store での配布
- ✅ インフラは無料枠で構築（Google Firebase等）
- ✅ UX：「全部自然言語だと面倒」を解決する工夫（テンプレート + 確認画面）

---

## 🎯 2. 要件定義

### 機能要件

#### 基本機能
1. **自然言語入力・AI解析**
   - テキスト入力：「ベンチプレス 10回 60kg」のように複数運動をまとめて入力可能
   - AI解析：運動名、回数、重量を自動抽出
   - 確認・編集画面：ユーザーが抽出結果を確認・修正可能

2. **メニュー記録・履歴管理**
   - セッション記録：日付、メニュー名、実施内容を保存
   - 複数パターン保存：「月曜の上半身」「金曜の下半身」など

3. **テンプレート機能**
   - セッションをテンプレート化して再利用
   - テンプレート一覧表示・削除・編集

4. **進捗トラッキング**
   - 過去セッション一覧（カレンダービュー）
   - 簡易統計：「ベンチプレス最高重量」など

### 非機能要件
- **オフライン対応**: インターネット接続なしで基本機能が動作
- **レスポンス**: NLP解析は1秒以内（デバイス内処理）
- **ストレージ**: SQLiteでローカル保存、初期容量100MB以下
- **UI応答性**: Jetpack Composeで60fps実現
- **拡張性**: 将来的にFirebase連携（クラウド同期）を追加可能

## 📊 5. データモデル

### テーブル定義

#### 1. WorkoutSession（筋トレセッション）
```sql
CREATE TABLE workout_session (
    id: Long PRIMARY KEY,
    date: LocalDate,
    menuName: String,              -- 例：「月曜の上半身」
    notes: String?,                -- オプション
    createdAt: LocalDateTime
);
```

#### 2. WorkoutExercise（各運動の詳細）
```sql
CREATE TABLE workout_exercise (
    id: Long PRIMARY KEY,
    sessionId: Long FOREIGN KEY → workout_session,
    name: String,                  -- 例：「ベンチプレス」
    sets: Int,
    reps: Int,
    weight: Double?,               -- kg, オプション
    notes: String?,
    order: Int                     -- 表示順序
);
```

#### 3. ExerciseTemplate（再利用テンプレート）
```sql
CREATE TABLE exercise_template (
    id: Long PRIMARY KEY,
    templateName: String,          -- 例：「月曜の上半身」
    createdAt: LocalDateTime
);
```

#### 4. TemplateExercise（テンプレート内の運動）
```sql
CREATE TABLE template_exercise (
    id: Long PRIMARY KEY,
    templateId: Long FOREIGN KEY → exercise_template,
    name: String,
    sets: Int,
    reps: Int,
    weight: Double?,
    order: Int
);
```

### データフロー
1. ユーザー入力（自然言語）→ NLPEngine.parse()
2. 抽出結果 → NLPConfirmScreen で表示
3. ユーザー確認・編集 → WorkoutRepository.saveSession()
4. SQLite に永続化
5. テンプレート化 → ExerciseTemplate + TemplateExercise に保存

## 🎬 6. UI/UX フロー

### 画面一覧と遷移

#### 1️⃣ **ホーム画面**
- **目的**: 今日のセッション開始、テンプレートクイック選択
- **コンポーネント**:
  - 「今日のセッション開始」ボタン（FloatingActionButton）
  - テンプレート一覧（カード表示、最多使用順）
  - 過去7日のセッション履歴ウィジェット
- **遷移**: テンプレート選択 → InputScreen, または InputScreen 直行

#### 2️⃣ **自然言語入力画面**
- **目的**: ユーザーが日本語でまとめて運動を入力
- **コンポーネント**:
  - 複数行テキストフィールド
  - 「解析」ボタン → NLPEngine.parse()
  - 「テンプレートから選択」ボタン（クイックアクセス）
- **入力例**:
  ```
  ベンチプレス 10回 60kg
  ダンベルフライ 12回 30kg
  インクラインベンチ 8回 70kg
  ```
- **遷移**: 解析成功 → NLPConfirmScreen, 失敗 → エラー表示 + 再入力

#### 3️⃣ **NLP確認・編集画面**
- **目的**: AI解析結果を表示し、ユーザーが確認・修正
- **コンポーネント**:
  - 運動リスト（チェックボックス + 運動名 + 回数 + 重量）
  - 編集ボタン（各運動ごと）
  - 「追加」ボタン（手動で運動を追加）
  - 「保存」ボタン → WorkoutRepository
  - 「テンプレートとして保存」チェックボックス
- **表示例**:
  ```
  ☑ ベンチプレス | 10回 | 60kg   [編集]
  ☑ ダンベルフライ | 12回 | 30kg  [編集]
  ☑ インクラインベンチ | 8回 | 70kg [編集]
  
  [+ 追加] [保存] [☐ テンプレートとして保存]
  ```
- **遷移**: 保存成功 → ホーム画面 + 成功トースト

#### 4️⃣ **テンプレート管理画面**
- **目的**: 保存したテンプレートの管理
- **コンポーネント**:
  - テンプレート一覧（使用頻度順）
  - 各テンプレートの「使用」「編集」「削除」ボタン
  - 「新規テンプレート作成」ボタン
- **遷移**: 「使用」→ セッションとして記録開始, 「編集」→ 編集画面

#### 5️⃣ **履歴・統計画面**
- **目的**: 過去のセッション一覧、進捗トラッキング
- **コンポーネント**:
  - カレンダービュー（セッション実施日をハイライト）
  - セッション一覧（日付でフィルタ可能）
  - 簡易統計：
    - 「過去30日の筋トレ回数」（グラフ）
    - 「ベンチプレス最高重量」（テーブル）
  - 各セッションの詳細表示・削除

### UX設計のポイント
✅ **テンプレート選択** → シンプルなクイックスタート  
✅ **複数行入力** → 効率的にメニューを記録  
✅ **NLP確認画面** → AIの誤りを防止、手動修正対応  
✅ **テンプレート化** → 同じメニューの再利用で手間削減  
✅ **統計・進捗** → モチベーション維持  

→ 「全部自然言語だと面倒」問題を、**テンプレート + 段階的入力** で解決

## 🤖 7. NLP実装詳細

### 解析フロー

```
ユーザー入力文字列
      │
      ▼
[1] テキスト前処理（改行分割、空白削除）
      │
      ▼
[2] ルールベース解析
    - 日本語トークン化（MeCab or 正規表現）
    - 辞書マッチング（運動名：ベンチプレス, スクワット等）
    - パターン抽出（正規表現：「(\d+)回」→ 回数）
      │
      ▼
[3] ML信頼度スコア（TensorFlow Lite）
    - 抽出結果の信頼度を0-1で計算
    - 信頼度 < 0.5 の場合は確認画面でユーザーに警告
      │
      ▼
[4] 結果JSON生成
    {
      "exercises": [
        {
          "name": "ベンチプレス",
          "reps": 10,
          "weight": 60,
          "confidence": 0.95
        },
        ...
      ]
    }
      │
      ▼
NLPConfirmScreen に表示
```

### 対応するジャンル
- **運動名**: ベンチプレス、スクワット、デッドリフト、ダンベルフライ等（拡張可能）
- **数値**: 回数、セット数、重量（kg/lb）、時間（秒/分）
- **言語**: 日本語（初版）、将来英語対応

### TensorFlow Liteモデル
- **モデルサイズ**: 5-10MB（デバイス内実行基準）
- **推論時間**: < 100ms（目安）
- **選定**: NLP用の軽量モデル（TBD、事前学習モデル利用予定）

### 無料インフラの構成

| 要件 | 選択肢 | 無料枠 | 備考 |
|------|--------|--------|------|

- **必須**: Google Play Developer アカウント（$25 一度きり）
- **流れ**:
  1. Android App Bundle(.aab)をビルド
  2. Play Console に登録・設定
  3. テスト → 本番リリース
- **スケジュール**: MVP完成後、デプロイプロセスで詳細化

### 初期デプロイ（MVP版）
- **対象**: オンデバイス処理のみ（クラウド非依存）
- **リリース**: Google Play Store（内部テスト → α → β → 本番）
